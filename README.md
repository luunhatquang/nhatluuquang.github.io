Mỗi thư mục bài chứa `index.html`, `style.css` đã sửa, `style-loi.css` gốc để đối chiếu, thư mục ảnh và `giai-thich.md` giải thích lỗi.

Website tĩnh, không cần cài thư viện. GitHub Pages phục vụ nội dung từ nhánh main, thư mục gốc. Đường dẫn CSS và ảnh dùng đường dẫn tương đối để hoạt động dưới tên repo.
